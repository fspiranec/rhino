Instagram Photo Saver

A one-click Chrome bookmark that saves the full-size photos from the Instagram post you have open.

1. Install it (once)

  1. Show Chrome's bookmarks bar with Ctrl + Shift + B.
  2. Drag this yellow button onto the bookmarks bar:
    📷 Save IG photos

Dragging doesn't work? Copy the code below, right-click the bookmarks bar, choose Add page…, name it "Save IG photos" and paste the code into the URL box.

2. Use it

  1. Open a post on instagram.com (its own page, or the pop-up you get by clicking a photo in a profile grid).
  2. Click Save IG photos on the bookmarks bar.
  3. The photos land in your Downloads folder, named like rhino_and_navel-DB5myQItFA9-1.jpg.

Posts with several photos: Instagram only loads the next one or two slides. Click the arrow through all the slides first, then click the bookmark. Videos can't be saved this way; take a screenshot with Win + Shift + S instead. The first time, Chrome may ask to allow multiple downloads from instagram.com: click Allow.
